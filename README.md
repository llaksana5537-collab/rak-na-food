# 🥗 รักนา แพลตฟอร์ม (Rak-Na Food Delivery Platform)

ระบบสั่งอาหารและบริหารจัดการเดลิเวอรีครบวงจร ประกอบด้วย 3 พอร์ทัลหลักที่เชื่อมต่อข้อมูลผ่าน LocalStorage แบบเรียลไทม์ ดีไซน์ระดับองค์กรแบบ Clean Fintech ใช้ฟอนต์ **Roboto** ควบคู่ **Prompt**, ภาพอาหารจริงคุณภาพสูง (100% Real HD Photography), ไอคอนเวกเตอร์ SVG มาตรฐานสากล ไร้อิโมจิการ์ตูน

## 🚀 วิธีการเปิดใช้งาน (How to Run)

ระบบทั้งหมดถูกออกแบบให้เป็น **Standalone Pure HTML/CSS/JavaScript** สามารถเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้ง Node.js หรือ build tools:

1. **เปิดผ่าน VS Code**:
   - เปิดโปรแกรม VS Code
   - ไปที่เมนู `File` -> `Open Folder...`
   - เลือกโฟลเดอร์ `c:\ระบบสั่งอาหาร`
   - คลิกขวาที่ไฟล์ `index.html` หรือ `hub.html` แล้วเลือก `Open with Live Server` หรือดับเบิลคลิกเปิดบนเบราว์เซอร์ได้ทันที

2. **เปิดโดยตรงในเบราว์เซอร์**:
   - ดับเบิลคลิกที่ไฟล์ [index.html](file:///c:/%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%B1%E0%B9%88%E0%B8%87%E0%B8%AD%E0%B8%B2%E0%B8%AB%E0%B8%B2%E0%B8%A3/index.html) เพื่อเข้าหน้าลูกค้า
   - ดับเบิลคลิกที่ไฟล์ [merchant.html](file:///c:/%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%B1%E0%B9%88%E0%B8%87%E0%B8%AD%E0%B8%B2%E0%B8%AB%E0%B8%B2%E0%B8%A3/merchant.html) เพื่อเข้าหน้าร้านค้า
   - ดับเบิลคลิกที่ไฟล์ [admin.html](file:///c:/%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%B1%E0%B9%88%E0%B8%87%E0%B8%AD%E0%B8%B2%E0%B8%AB%E0%B8%B2%E0%B8%A3/admin.html) เพื่อเข้าหน้าแอดมินกลาง
   - ดับเบิลคลิกที่ไฟล์ [hub.html](file:///c:/%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%B1%E0%B9%88%E0%B8%87%E0%B8%AD%E0%B8%B2%E0%B8%AB%E0%B8%B2%E0%B8%A3/hub.html) เพื่อดูทุกระบบในหน้าเดียวแบบ Presentation Mode

## 🍱 ฟีเจอร์หลักในแต่ละระบบ

### 1. Customer Web App (`index.html`)
- **ดีไซน์ Mobile-First สะอาดตา ทันสมัย**: ไม่มีขอบโทรศัพท์จำลอง (No Phone Bezel/Notch) เต็มพื้นที่บนจอมือถือจริง และจัดกึ่งกลางสวยงามบนจอคอมพิวเตอร์
- **ระบบปักหมุดที่อยู่จัดส่งบนแผนที่จริง จังหวัดประจวบคีรีขันธ์ (Interactive Map Pinning)**: ขับเคลื่อนด้วย Leaflet.js & OpenStreetMap พิกัดศูนย์กลาง อ.เมืองประจวบคีรีขันธ์, จุดสำคัญยอดนิยม (สละชีพ, อ่าวมะนาว กองบิน 5, เขาช่องกระจก, อ่าวน้อย, ปากน้ำปราณ, หัวหิน), พร้อมระบุบ้านเลขที่/ชื่ออาคาร และระบุจุดส่งตรงไหน (โต๊ะหน้าบ้าน, แขวนที่รั้ว, ป้อม รปภ., ส่งถึงมือ, จุดเดลิเวอรี่)
- 12 หมวดหมู่รูปถ่ายจริงในรูปแบบ Story Circle ไร้อิโมจิการ์ตูน
- 12 ร้านอาหารพาร์ทเนอร์ยอดนิยม พร้อมเมนูหลากหลายและภาพถ่าย HD จริง 100%
- ป๊อปอัปเลือกออปชัน (ระดับความเผ็ด, ท็อปปิ้ง, ไข่ดาว, โน้ต)
- **ระบบชำระเงิน Thai QR Payment (พร้อมเพย์)**: ใช้ภาพ QR Code พร้อมเพย์จริงที่แนบมา (น.ส. ลักษณา มีท่อธาร, KBank)
- **ระบบชำระเงิน Mobile Banking**: รองรับ 6 ธนาคารชั้นนำในไทย (K PLUS, SCB EASY, Bangkok Bank, Krungthai NEXT, KMA Krungsri, ttb touch) พร้อมปุ่มคัดลอกเลขบัญชี และระบบแนบสลิปโอนเงิน
- แทร็กกิ้งแผนที่และสเต็ปสถานะจัดส่ง 4 ขั้นตอน
- รองรับ Dark Mode และเสียงสังเคราะห์ Web Audio API

### 2. Merchant Portal (`merchant.html`)
- เลือกร้านอาหารที่เข้าจัดการได้ทั้ง 12 ร้าน
- บอร์ดรับออเดอร์สด (Live Orders) พร้อมแจ้งเตือนเสียงและปุ่มรับ/ปรุง/ส่งอาหาร
- จัดการเมนูและสต๊อก พร้อมสวิตช์เปิด/ปิด "พร้อมขาย / ของหมดชั่วคราว"
- กำหนดโปรโมชั่นและส่วนลดร้านค้า
- กราฟแนวโน้มยอดขายรายสัปดาห์ (Vector SVG Line Chart)
- ข้อมูลโปรไฟล์ร้านค้าและสวิตช์เปิดรับออเดอร์

### 3. Central Admin Dashboard (`admin.html`)
- มอนิเตอร์สถิติรวม GMV, กำไร GP, จำนวนออเดอร์, ไรเดอร์ที่พร้อมวิ่ง
- ตารางจัดการร้านค้าพาร์ทเนอร์และปรับอัตรา GP แต่ละร้าน
- จัดการไรเดอร์ (ทะเบียนรถ, เบอร์โทร, ทริปสะสม, คะแนนรีวิว)
- จัดการตั๋วปัญหาลูกค้าและปุ่ม "อนุมัติคืนเงิน (Approve Refund)"
- ควบคุมโค้ดส่วนลดกลาง (RAKNA50, FREESHIP, YUMMY20) และข้อความแบนเนอร์

## 🔄 การเชื่อมโยงข้อมูล (Data Sync)
ระบบใช้ `localStorage` ร่วมกันระหว่างทุกหน้า:
- คีย์ `rakna_restaurants`: เก็บข้อมูล 12 ร้านค้าและเมนูอาหาร
- คีย์ `rakna_orders`: เก็บประวัติและออเดอร์สดที่ลูกค้ากดสั่ง
- คีย์ `rakna_riders` & `rakna_tickets`: เก็บข้อมูลไรเดอร์และการคืนเงิน
